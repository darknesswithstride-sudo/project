# OmniForge AI v4.0 — Forge Studio

## Integrated reference-to-asset workflow
- Reference image preview and validated local upload.
- Single-image generation using the currently configured backend (local TripoSR in free-local mode).
- Task status checking with generated model path handoff into local finishing.
- AI/offline detail recommendation feeding the existing Blender production pipeline.
- Asset/backend catalog and visible stage state.
- Existing rigging, local animation, coding agent, Git worktrees, benchmark, and diagnostics remain available in their sections.

## Important limits
- Single-image reconstruction estimates unseen surfaces.
- Local rigging and motion features require compatible rigs/tools and may need manual cleanup.
- TRELLIS/Hunyuan3D are inventory-detected candidates; this release does not claim they are end-to-end integrated.
- Blender and model inference require local installations and have not been exercised on every target PC.
- The app uses local services in free-local mode; choosing a cloud provider is a separate configuration and may require paid access.

## New endpoint
`GET /api/studio/catalog` returns asset inventory, detected 3D backends, production status, and the documented workflow stages.
